# Hintergrundmusik

Lege hier deinen Musik-Track ab, z. B. `theme.mp3`.

- Standard-Dateiname laut Template: `theme.mp3`
  (anpassbar pro Seite ueber das Frontmatter-Feld `musik`).
- Format: komprimiertes MP3, moeglichst < 3 MB.
- Verwende nur Musik, an der du die Rechte besitzt
  (Eigenkomposition oder lizenzfreie Stuecke).

Ohne hinterlegte Datei bleibt der Musik-Knopf sichtbar und funktionslos —
die Seite funktioniert trotzdem fehlerfrei.
